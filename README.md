# Business HQ

Portables Business Memory (reines Markdown). Getrennt von allen anderen Vaults und Projekten.

## Schreibregeln
| Bereich | Agenten | Mensch |
|---|---|---|
| `00 Inbox/` | dürfen **neue** Entwürfe anlegen, nie überschreiben | sichtet, verschiebt, löscht |
| `STATUS.md` | wird nach jedem Lauf neu geschrieben (nur Betriebsdaten) | liest |
| `01`–`07` | **nur lesen** | schreibt, gibt frei |

- Ein Entwurf wird erst Wissen, wenn er von Hand aus der Inbox in einen Fachordner verschoben wird.
- Entscheidungen (`07 Decisions/`) werden nie automatisch geändert.
- Niemals hier ablegen: Secrets, API-Keys, Trading-Credentials, Kundendaten (insb. Dokunaro/BauEcho).

## Ordner
- `00 Inbox` – Agenten-Entwürfe (Scout-Reports unter `Scout/`)
- `01 Strategy` – Ziele, Leitplanken, Budget
- `02 Ventures` – je Geschäftsidee eine Notiz (Vorlage: `Templates/Venture.md`)
- `03 YouTube Factory` – Themen, Skripte, Produktionsstatus
- `04 Research` – geprüfte Recherche
- `05 Agents & Workflows` – Beschreibung der laufenden Automationen
- `06 Experiments & Results` – Hypothese → Test → Ergebnis
- `07 Decisions` – freigegebene Entscheidungen (Vorlage: `Templates/Decision.md`)
